# Advent of Code 2022

Elixir solutions for Advent of Code 2022. This repository currently includes solutions for days 1 through 5.

## Run a solution

Install Elixir, then run a script from the repository root:

```sh
elixir advent1.exs
elixir advent2.exs
elixir advent3.exs
elixir advent4.exs
elixir advent5.exs
```

Each script reads its corresponding input file from `inputs/` and prints its result to the terminal. Run from the repository root so the relative input paths resolve.

## Files

- `adventN.exs`: solution for day N
- `inputs/adventNinput.txt`: input used by that solution
